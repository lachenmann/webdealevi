# Fuentes musicales incorporadas

Estos son **archivos originales sin modificaciones**, incluidos exclusivamente
para el grabado del monocordio y la auditoría tipográfica.

- `Leland.otf`: MuseScore BVBA, Leland v0.80, SIL Open Font License 1.1.
  Origen: https://github.com/MuseScoreFonts/Leland/blob/main/Leland.otf
  Blob GitHub original: `4049829ece8fec2af32ae752b02e1960915c4959`.
  Uso principal: claves, cabezas de nota, alteraciones convencionales,
  cuarto de tono Stein–Zimmermann (E280/E282).
- `Ekmelos72edo.woff2`: Thomas Richter, Ekmelos 72-EDO, SIL Open Font
  License 1.1. Origen:
  https://github.com/tr-igem/ekmelos/blob/main/fonts/woff/Ekmelos72edo.woff2
  Blob GitHub original: `0dd430950b94d031bf4be604e809454fdc5e8740`.
  Uso especializado: glifos Sims y Wyschnegradsky de 72-EDO.
  Esta versión reducida **no contiene** E280/E282.
- Las licencias completas y avisos de copyright originales se conservan
  en `OFL-Leland.txt` y `OFL-Ekmelos.txt`.

**Política del proyecto:** los signos geométricos de inspiración Danny Wier
(±⅙ y ±¹⁄₁₂) y la indicación de octavo de tono conservan sus SVG originales.
Los complementos de Ekmelos se comparan/documentan sin alterar silenciosamente
la convención notacional del taller. MIDIDESI/Tempera no se redistribuye.

Las tipografías conservan sus nombres originales y sus condiciones OFL.
No se incluyen las fuentes descargadas de Drive con derechos no verificados.
