# Editorial Policy — bootstrap

## Fuente pública

El repositorio público es una superficie editorial y de publicación; no es un espejo del Vault privado de Obsidian.

## Flujo

Obsidian → Markdown estándar + YAML → Git → Quarto → web.

## Reglas

1. No subir notas privadas, diarios, borradores sensibles ni material fuente no destinado a publicación.
2. Preferir Markdown estándar para contenido editorial nuevo.
3. Conservar PDF, audio y otros binarios como recursos cuando constituyan la obra o su documentación primaria.
4. Conservar aplicaciones autónomas HTML/CSS/JavaScript como recursos estáticos; Quarto las cataloga y enlaza, no las reimplementa.
5. Mantener las URLs existentes siempre que sea razonable; cuando cambien, registrar una estrategia explícita de redirección.
6. Declarar la licencia por contenido o colección cuando corresponda.
7. No modificar configuración de Pages, DNS ni dominio durante la fase de bootstrap.

## Licencia literaria pública por defecto

Salvo instrucción autoral explícita en contrario, las nuevas obras literarias públicas de Alevi Peña se publican bajo **Creative Commons Atribución–NoComercial–SinDerivadas 4.0 Internacional (`CC BY-NC-ND 4.0`)**.

- `BY`: toda reutilización permitida debe atribuir claramente la autoría.
- `NC`: no se autoriza la explotación comercial de la obra bajo esta licencia.
- `ND`: no se autoriza distribuir versiones modificadas, adaptadas o derivadas bajo esta licencia.
- La licencia no elimina las excepciones y limitaciones legales aplicables, como la cita legítima.
- Una instrucción autoral posterior y explícita puede actualizar la licencia mostrada por el sitio para una obra concreta.
- No se reescriben retroactivamente concesiones de licencia ya otorgadas en otras colecciones o publicaciones externas.

Esta política se aplica desde ALEVI-WEB-0008 a la nueva expansión literaria y, por instrucción autoral expresa, a *La Muerte de Nicanor*.
