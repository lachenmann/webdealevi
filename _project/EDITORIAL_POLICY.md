# Editorial Policy — bootstrap

## Fuente pública

El repositorio público es una superficie editorial y de publicación; no es un espejo del Vault privado de Obsidian.

## Flujo

Obsidian → Markdown estándar + YAML → Git → Quarto → web.

## Reglas

1. No subir notas privadas, diarios, borradores sensibles ni material fuente no destinado a publicación.
2. Preferir Markdown estándar para contenido editorial nuevo.
3. Conservar PDF, audio y otros binarios como recursos cuando constituyan la obra o su documentación primaria.
4. Conservar aplicaciones autónomas HTML/CSS/JavaScript como recursos estáticos; Quarto las cataloga y enlaza, no las reimplementa.
5. Mantener las URLs existentes siempre que sea razonable; cuando cambien, registrar una estrategia explícita de redirección.
6. Declarar la licencia por contenido o colección cuando corresponda.
7. No modificar configuración de Pages, DNS ni dominio durante la fase de bootstrap.
